# Example app for CI Hexlet course

Starting boilerplate of [Strapi](https://strapi.io/) application

## Зачем это нужно

Подопытное приложение для курса по непрерывной интеграции. Само по себе оно
неинтересно: это заготовка [Strapi](https://strapi.io/), и её задача просто
собираться и проходить тесты.

Ценность в обвязке вокруг: на этом репозитории настраивают пайплайн, учатся
читать красный CI и чинить сборку.

## System requirements

* NodeJS >= 26
* pnpm >= 11
* Make

## Using

```sh
make setup
make start
```

## Run tests

```sh
make test
```

## Run linter

```sh
make lint
```
